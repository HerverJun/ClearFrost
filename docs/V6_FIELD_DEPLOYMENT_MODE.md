# V6 现场轻量落地模式

V6_test 默认以现场轻量部署为主，严格模型准入和回放验证属于工程师高级维护能力。班组长和一线人员只需要关注工位配置、当前是否可以生产、设备状态和待处理问题。

## 现场默认流程

1. 打开“工位模板与配置迁移”。
2. 在“工位快速配置”选择 N5、N6、W5、W6 或电加热螺钉检测模板。
3. 模板只会载入参数，不会自动保存；保存前必须确认相机序列号、PLC IP、PLC 端口、触发源和模型选择。
4. 保存后回到现场诊断，先看“当前是否可以生产”，再看“待处理问题”。
5. 班组长需要转交问题时，使用“复制故障摘要”；工程师需要完整排查材料时，再导出诊断包。

## 工位模板

内置模板覆盖：

- N5 遥控器漏装
- N5 螺钉检测
- N6 遥控器漏装
- N6 螺钉检测
- W5 螺钉检测
- W6 螺钉检测
- 电加热螺钉检测

模板会带入检测类型、目标标签、目标数量、相机品牌、推荐曝光、推荐增益、PLC 协议、PLC 地址、触发源和默认存储路径。现场仍应按设备铭牌和 PLC 实际地址复核。

## 触发源选择

`TriggerSource` 支持三种模式：

- `PLC`：自动生产由 PLC 触发，PLC 未连接会阻断自动生产。
- `SerialPhotoelectric`：自动生产由串口光电触发，未连接串口触发器会提示先处理触发器。
- `Manual`：不启动 PLC 或串口自动触发，可使用手动拍照检测；现场诊断会显示“可进行手动检测；自动生产触发未启用。”

非 PLC 触发时，PLC 未连接不会作为默认待处理问题显示，避免误导班组长。

## 故障摘要与诊断包

“复制故障摘要”面向班组长和一线交接，内容包括时间、工位、触发源、结论、相机、PLC、模型、存储和待处理项。它适合粘贴到班组群或交接记录。

“导出诊断包”面向工程师，包含更完整的日志、配置、链路状态、校验字段和历史材料。需要定位模型、数据或设备深层问题时再使用。

## 现场轻量模式

- 默认 `RequireApprovedModelsForProduction=false`。
- 默认 `StrictModelPackageMode=false`。
- 默认 `ModelPackageDirectory=models`。
- 普通 ONNX 和旧式模型引用可以进入生产准备流程。
- 不强制检查模型审批证据。
- 仍会检查模型文件存在性、运行时加载、Recipe 与 AppConfig 一致性、存储路径、PLC、相机和触发源等基础条件。
- 诊断摘要会记录：`当前为现场轻量模式，未强制模型审批证据。`

## 工程师高级维护

工程师可在“工程师详情（高级）”“视觉调试（工程师）”和记录追溯中的工程师折叠区处理：

- 模型调试和规则验证
- 历史样本复判
- 诊断包和交接报告
- 模型回放验证、模型对比和验证记录
- Replay、Evidence、Gate、Hash 等内部字段

这些内容默认不作为一线操作入口，只有排查、上线验证或追溯审计时使用。

## 严格模型准入

严格模式适合高风险工位、质量追溯要求高、模型频繁迭代或客户明确要求审批证据的场景。开启后：

- `RequireApprovedModelsForProduction=true`
- 未批准模型、非包模型、Gate 缺失或验证记录失效会阻断生产模型上线。
- 一线主提示统一为：`当前模型未完成上线验证，请联系工程师完成模型验证，或切换回已验证模型。`
- 内部错误码仍保留在工程师详情、日志和诊断包中。

运行配置示例：

```json
{
  "TriggerSource": "PLC",
  "ModelPackageDirectory": "models",
  "StrictModelPackageMode": false,
  "RequireApprovedModelsForProduction": false
}
```

- 关闭严格准入：将 `RequireApprovedModelsForProduction` 设为 `false`。
- 开启严格准入：将 `RequireApprovedModelsForProduction` 设为 `true`。
- `StrictModelPackageMode` 继续默认 `false`，除非工程师明确需要强制模型包结构校验。
- 从 V5.9.x/main 风格配置迁移到 V6_test 时，旧配置缺少该字段不会自动开启审批。
- 已有 V6 配置显式写入 `RequireApprovedModelsForProduction=true` 时会保留用户选择。

## 诊断中心怎么看

1. 先看“当前是否可以生产”。
2. 再看“待处理问题”，每条问题都有下一步建议。
3. 班组长转交问题时复制故障摘要。
4. 工程师需要排查时，再展开“工程师详情（高级）”查看 P95/P99、队列、审计链、启动诊断原始项和内部错误码。

## 视觉调试工作台怎么用

1. 选择场景：螺钉数量检测、遥控器漏装检测、线序顺序检测、相对位置检测或自定义规则。
2. 获取图片：获取当前相机单帧，或从历史记录选择样本。
3. 运行验证：运行当前规则，或批量验证历史样本。

本地图片导入入口暂未开放。规则 JSON 默认隐藏在“高级：查看/编辑规则 JSON”中，保存前会校验格式，无效 JSON 不允许保存。

## 分支说明

- `main` 仍是 V5.9.x 产线稳定版。
- `V6_test` 是研发试验分支。
- 本模式只在 `V6_test` 工作，禁止合并、重写或删除 `main`。
